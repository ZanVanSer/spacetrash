`Space Trash` is a top-down survivors-like shooter built with the [LÖVE](https://love2d.org/) framework. Fight through escalating enemy waves, collect XP, evolve your weapons through synergies, and push each run further with new ships, passives, and unlocks.

## Features

- Fast-paced survival runs with escalating waves and boss fights
- Multiple ships, weapons, and passive upgrades to shape each build
- Weapon evolution system with stronger endgame synergies
- Unlockable library and run stats for long-term progression
- Data-driven content powered by JSON definitions

## Stack

- LÖVE (Love2D)
- Lua
- JSON data files

## Commands

```bash
love .
open -a love .
```

## Getting Started

1. Install [LÖVE 11.x](https://love2d.org/).

2. Clone the repository:

```bash
git clone https://github.com/yourusername/spacetrash.git
cd spacetrash
```

3. Run the game:

```bash
# Linux
love .

# macOS
open -a love .

# Windows (PowerShell, if LOVE is in PATH)
love .
```
